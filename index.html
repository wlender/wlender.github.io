Плейлисты TV

Личное приложение для Android TV, которое показывает плейлисты с YouTube-каналов владельца и запоминает, что уже просмотрено.

Приложение не распространяется публично и предназначено только для личного использования его автором.

Приложение использует YouTube API Services.
