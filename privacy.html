Политика конфиденциальности

Плейлисты TV — личное приложение для Android TV, предназначенное только для использования его автором.

Какие данные используются

После входа через Google приложение с правом только на чтение (youtube.readonly) получает через YouTube API Services список плейлистов пользователя, их содержимое, названия, даты и превью видео.

Где хранятся данные

Все данные хранятся только локально на устройстве пользователя: токены доступа, кэш плейлистов и отметки о просмотре. Приложение не передаёт данные на сторонние серверы, не продаёт их и не использует для рекламы.

Удаление данных

Данные удаляются при удалении канала в приложении, при очистке данных приложения или при его удалении с устройства. Отозвать доступ можно в любой момент на странице https://myaccount.google.com/permissions.

YouTube и Google

Приложение использует YouTube API Services. Используя его, вы соглашаетесь с Условиями использования YouTube. Обработка данных Google регулируется Политикой конфиденциальности Google.
